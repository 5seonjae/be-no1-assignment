## 📌 프로젝트 개요

이 프로젝트는 Java를 활용한 단계별 사칙연산 계산기 구현 과제로, 각 단계별로 기능을 확장하며 개발하였습니다.

### 🔹 Level 1
- 0보다 크거나 같은 정수에 대한 사칙연산 기능을 구현하였습니다.
- 연산자 입력에 따라 결과를 출력하는 기본 구조입니다.

### 🔹 Level 2
- `CalculatorLv2` 클래스를 사용하여 연산 기능을 구조화하였습니다.
- 코드의 재사용성과 가독성을 높였습니다.

### 🔹 Level 3
- Java의 **제네릭**과 **열거형(enum)**을 활용한 고급 계산기를 구현하였습니다.
- 사용자 입력을 받아 `+`, `-`, `*`, `/` 연산을 수행하며
- `int`와 `double` 타입 모두 처리할 수 있도록 제네릭을 적용했습니다.
